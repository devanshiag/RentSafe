# RentSafe - A Rent Management Portal

A web application built using Flask for managing rent payments, lease information, notifications, and more. This application allows landlords and tenants to manage leases, send email notifications for rent dues, and track rent payments.

## Features
- Tenant Dashboard: Tenants can view their lease information and rent payment status.
- Lease Management: Landlords can manage tenant leases, including rent due dates.
- Email Notifications: Automated email notifications for rent due reminders.
- In-App Notifications: Real-time notifications to users about rent dues.
- Grievance Redressal: Tenants can submit grievances for resolution.
- Admin Console: Landlords can manage tenants and lease data
